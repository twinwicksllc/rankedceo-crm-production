## A mistake of mine, caught and fixed

My first rollback revoked `authenticated` from `get_user_org_id`, `is_org_member` and `is_org_owner`. Those three already grant `authenticated` live (VERIFIED, `proacl` read). The rollback would have broken the policies on `drafts`, `org_members`, `organizations` and `org_invitations`, and my local "identical to the original" check passed only because my test copy assumed all functions were revoked. I read the live ACLs, removed those three from both the fix and the rollback, made the test copy match the live ACLs, and re-ran everything.

## Lessons recorded as rules

- A rollback is only verified against the real ACLs, not against a test copy built from an assumption. Read the live ACL of every function the rollback touches.
- A function that is a no-op for everyone because nobody can run it is not "secure". Check what the policies and routes need before granting or revoking.
